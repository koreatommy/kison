http://localhost:3000/dashboard/startup-support 페이지의 UI/UX 디자인을 전면 개편해줘.

단, 이번 작업은 “디자인 개편” 작업이다. 기존 기능, 데이터 흐름, AI 호출 로직, 단계 이동 로직, HTML/PDF 저장 로직, 입력값 처리 로직은 절대 깨뜨리지 말고 유지해야 한다.

작업 전 반드시 플랜모드로 먼저 `startup-support-design-renewal-plan.md` 개발 플랜을 작성해줘.  
플랜 작성 후 내가 승인하면 구현을 진행한다.

## 1. 반드시 분석할 기존 자료

다음 파일과 현재 화면 구조를 먼저 분석해줘.

- 현재 페이지: `http://localhost:3000/dashboard/startup-support`
- 관련 컴포넌트: 
- 기존 디자인 캡처 이미지 2개
  - 시작 화면
  - 팀 정보 입력 화면
- 최종 결과 HTML 보고서 파일: `사업계획서_ai.html`
- 신청서 양식 기준 문서:
  - `2026 대한민국 청소년 창업경진대회 사업계획서 신청서 양식`
  - 양식의 목차, 표, 주요 항목 구조는 결과 페이지 구성에 반드시 반영


## 2. 현재 디자인에서 개선할 문제

현재 화면은 기본 동작은 괜찮지만 다음 문제가 있다.

1. 전체적으로 여백이 과도하고 콘텐츠 밀도가 낮다.
2. 질문지와 입력 폼이 단순 카드 형태라 사용자가 작성 중인 맥락을 파악하기 어렵다.
3. 폰트 크기, 제목 위계, 설명 문구, 경고 문구의 시각적 우선순위가 약하다.
4. 진행 단계는 보이지만 “지금 무엇을 왜 입력하는지”가 부족하다.
5. AI 생성 결과 페이지가 단순 텍스트/테이블 느낌이라 보고서 완성도가 낮아 보인다.
6. 아이템 생성, 아이템 평가, 최종 결과 화면은 사용자가 비교·판단·확정하기 쉽게 재설계해야 한다.
7. 최종 결과는 청소년 창업경진대회 사업계획서 작성 전 단계의 “정리된 보고서”처럼 보여야 한다.

## 3. 디자인 개편 목표

다음 방향으로 UI/UX를 개선해줘.

### 핵심 목표

- 청소년과 지도교사가 보기 쉬운 구조
- 입력 단계는 질문지/워크북 느낌
- AI 생성 결과는 보고서/심사자료 느낌
- 최종 결과는 HTML/PDF 저장 시 그대로 제출 준비 자료처럼 보이게 구성
- 기존 보라색 포인트 컬러와 단계별 애니메이션은 유지하되 더 정돈된 디자인으로 개선
- 모바일보다는 데스크톱 사용성을 우선하되 반응형 기본 대응

## 4. 디자인 시스템 분리

디자인 개편을 위해 별도 디자인 시스템을 만들어줘.

예상 파일 예시:

- `src/components/dashboard/startup-support/design-system.ts`
- 또는 `src/components/dashboard/startup-support/ui/*`

디자인 시스템에는 다음 요소를 포함해줘.

### 색상

- Primary: 노란색 계열
- Secondary: 블루/인디고 계열
- Accent: 결과 강조용 오렌지 또는 앰버 계열
- Background: 단조로운 회색 배경 대신 섹션 구분이 되는 부드러운 그레이/화이트 조합
- Border: 연한 그레이
- Success / Warning / Error 상태 색상 정리

### 타이포그래피

- 페이지 타이틀
- 단계 타이틀
- 질문 타이틀
- 설명 문구
- 도움말 문구
- 결과 카드 타이틀
- 보고서 본문 텍스트
- 점수/랭킹 숫자 스타일

현재보다 제목과 본문 위계를 명확히 해줘.

### 공통 컴포넌트

가능하면 다음 공통 UI 컴포넌트로 분리해줘.

- `StepShell`
- `StepHeader`
- `ProgressStepper`
- `QuestionCard`
- `InputGroup`
- `HelpText`
- `WarningBox`
- `ResultCard`
- `ReportSection`
- `ScoreBadge`
- `InsightBox`
- `ComparisonTable`
- `FinalReportPreview`

기존 기능과 상태 관리 구조를 크게 바꾸지 말고, 디자인 레이어 중심으로 분리해줘.

## 5. 전체 레이아웃 개편

현재 상단 진행바는 유지하되 더 보기 좋게 개선해줘.

### 상단 진행 단계

현재 단계:

1. 시작
2. 팀 정보
3. 문제 선택
4. 문제 구체화
5. 아이템 생성
6. 아이템 평가
7. 후보 선정
8. 최종 확정
9. 결과 확인

개선 방향:

- 단계 번호 + 단계명 + 짧은 설명이 보이도록 개선
- 현재 단계는 명확히 강조
- 완료된 단계는 체크 아이콘 또는 완료 스타일
- 아직 진행 전 단계는 비활성 스타일
- 상단 고정 또는 스크롤 시 자연스럽게 유지
- 기존 단계별 애니메이션 효과는 유지

### 본문 영역

- 최대 폭을 현재보다 넓혀서 보고서형 결과도 잘 보이게 구성
- 입력 단계는 860~960px 중심 정렬
- 결과 단계는 1040~1200px까지 확장 가능
- 과도한 빈 공간 제거
- 카드 간 간격을 일관되게 정리

### 하단 네비게이션

- 기존 이전/다음 버튼 로직 유지
- 버튼 디자인 개선
- 다음 단계로 넘어가기 위한 조건 미충족 시, 하단에 명확한 안내 표시
- “다음” 버튼 비활성 상태를 더 분명하게 표현

## 6. 시작 화면 개선

현재 시작 화면은 너무 단순하다.

다음 내용을 포함해 더 신뢰감 있게 개선해줘.

- 서비스명: `AI 창업 아이템 선정하기`
- 짧은 설명: “문제 발견부터 아이템 생성, 평가, 최종 보고서까지 한 번에 정리합니다.”
- 주요 진행 흐름 4단계 카드:
  1. 팀 정보 입력
  2. 문제 선택 및 구체화
  3. AI 아이템 생성·평가
  4. 최종 보고서 저장
- 개인정보/저장 안내 박스는 유지하되 문구 가독성 개선
- Claude API Key 설정 버튼은 보조 액션으로 정리
- 시작 버튼은 명확한 Primary CTA로 표시
- 히어로 영역에는 아이콘 또는 미니 일러스트 느낌의 시각 요소 추가 가능

## 7. 팀 정보 입력 화면 개선

현재 팀 정보 화면은 카드가 단순하고 입력 필드가 작아 보인다.

개선 방향:

- “우리 팀 정보 입력” 제목 아래에 이 정보가 최종 보고서와 신청서에 어떻게 사용되는지 설명
- 팀명 입력 카드와 구성원 카드 분리
- 구성원 입력은 표 형태와 카드 형태의 장점을 섞어 정리
- 학교 / 학년 / 이름 필드의 폭과 정렬 개선
- 구성원 추가 버튼은 명확하게 우측 상단 배치
- 삭제 아이콘은 시각적으로 너무 약하지 않게 정리
- 필수값 오류 메시지는 입력 필드 바로 아래에 표시
- 최소 1명 이상 입력이 필요함을 명확히 표시
- 신청서 양식의 “팀 구성” 표 구조와 연결될 수 있도록 구성

## 8. 문제 선택 / 문제 구체화 화면 개선

문제 선택 화면은 워크북 느낌을 강화해줘.

- 문제 분야 선택 카드는 아이콘 + 분야명 + 짧은 예시 설명 포함
- 선택된 분야는 강하게 강조
- 다중 선택 가능 여부가 명확히 보이게 표시
- 사용자가 선택한 분야가 이후 AI 아이템 생성에 반영된다는 설명 추가

문제 구체화 화면은 질문지 형태로 개선해줘.

- 질문 하나하나를 `QuestionCard` 형태로 구성
- 질문 번호 표시
- 답변 예시 또는 작성 팁 표시
- 답변 입력 영역은 충분한 높이 확보
- 사용자가 “문제 발생 장소, 대상 고객, 불편 순간, 기존 해결책, 기존 해결책의 한계, 해결 후 변화”를 명확히 작성할 수 있도록 구성

## 9. 아이템 생성 결과 페이지 집중 개선

이 페이지가 가장 중요하다.

현재 AI가 생성한 후보 아이템을 단순 목록이 아니라 “후보 아이템 리포트”처럼 보여줘.

각 후보 아이템 카드는 다음 정보를 보기 좋게 표시한다.

- 후보 번호
- 아이템명
- 한 줄 설명
- 해결하는 문제
- 주요 고객
- 핵심 기능
- 차별성
- 사회적 가치
- 실행 난이도
- 예상 시제품 형태
- 총점 또는 추천도

디자인 방향:

- 카드형 비교 구조
- 우수 후보는 시각적으로 강조
- 점수는 `ScoreBadge` 형태로 표시
- 긴 문장은 접기/펼치기 또는 섹션 구분으로 가독성 확보
- “청소년이 실제로 만들 수 있는가” 관점이 보이도록 실행 가능성 표시
- 후보 간 차이를 한눈에 볼 수 있는 요약 비교 테이블 추가 가능

중요:
기존 AI 생성 데이터 구조를 변경하지 말고, 이미 존재하는 데이터 필드를 기준으로 표시 방식을 개선한다. 필요한 경우 안전한 fallback 표시만 추가한다.

## 10. 아이템 평가 페이지 집중 개선

아이템 평가 화면은 심사표/평가 리포트 느낌으로 개선해줘.

평가 기준은 현재 사용 중인 기준을 그대로 유지한다.

- 문제 명확성 20점
- 고객 명확성 15점
- 해결 적합성 20점
- 차별성 15점
- 실행 가능성 15점
- 사회적 가치 15점

개선 방향:

- 각 아이템별 총점과 세부 점수를 시각적으로 비교
- 6개 평가 기준을 레이더 차트처럼 보이게 할 수 있으면 좋지만, 새 라이브러리 추가가 부담되면 막대형 점수 표시로 구현
- 평가 사유를 항목별로 정리
- 상위 후보와 하위 후보의 차이가 명확히 보이게 구성
- 사용자가 최종 후보를 선택하기 쉽게 “추천 의견” 또는 “AI 평가 요약” 박스 표시
- 단순 점수 나열이 아니라 심사위원이 보는 평가표처럼 구성

주의:
점수 계산 로직은 절대 변경하지 않는다. 표시 방식만 변경한다.

## 11. 후보 선정 페이지 개선

사용자가 최종 후보 3개를 고르는 화면은 선택 행위가 명확해야 한다.

- 후보 아이템 카드에서 선택 가능
- 1순위 / 2순위 / 3순위가 시각적으로 분명히 구분
- 선택 이유 입력란을 더 보기 좋게 구성
- 선택 완료 여부를 하단 또는 우측 요약 패널에 표시
- 이미 선택한 아이템은 중복 선택되지 않게 기존 로직 유지
- 선택 이유가 최종 보고서에 들어간다는 설명 추가

## 12. 최종 확정 페이지 개선

최종 아이템을 확정하는 화면은 “최종 검토” 느낌으로 구성해줘.

- 최종 후보 3개 비교
- 각 후보의 장점/보완점 요약
- 최종 선택 아이템 강조
- 최종 선정 이유 입력/확인 영역 개선
- 확정 전 체크리스트 표시:
  - 문제와 고객이 명확한가?
  - 청소년 팀이 실행 가능한가?
  - 신청서 항목에 연결 가능한가?
  - 사회적 가치가 드러나는가?
  - 차별성이 있는가?

## 13. 결과 확인 페이지를 보고서 형태로 전면 개선

최종 결과 페이지는 가장 중요하다.

첨부된 `사업계획서_ai.html` 보고서 구조를 참고해서 웹 화면에서도 “보고서 미리보기”처럼 보여야 한다.

보고서 화면 구성 예시:

### 상단 요약 영역

- 보고서 제목: `창업 아이템 선정 결과 보고서`
- 팀명
- 최종 아이템명
- 작성일
- 핵심 한 줄 설명
- 선택 문제 분야
- 주요 고객
- 종합 평가 점수

### 섹션 구성

다음 순서로 보고서형 섹션을 구성해줘.

1. 팀 정보
2. 해결하고 싶은 문제
3. AI 창업 아이템 후보
4. 최종 후보 3개
5. 최종 창업 아이템
6. 신청서 핵심 작성 문안
7. 사업계획서 본문 확장 초안
8. 다음 단계
9. 보완 필요사항

각 섹션은 `ReportSection` 컴포넌트로 통일감 있게 구성한다.

### 보고서 디자인 방향

- A4 보고서 느낌의 흰색 문서 카드
- 섹션 번호와 제목 명확히 표시
- 표, 요약 박스, 인사이트 박스, 체크리스트를 적절히 사용
- 긴 본문은 읽기 편하게 문단 폭과 행간 조정
- 최종 아이템 정보는 별도 강조 카드로 표시
- “신청서에 바로 옮길 수 있는 문안”은 복사하기 쉬운 박스 형태로 표시
- “추후 조사 필요” 문구는 Warning 스타일로 표시
- HTML/PDF 저장 시에도 깨지지 않는 구조로 설계

## 14. 신청서 양식과 연결되는 보고서 구조 반영

결과 보고서는 단순 요약이 아니라 2026 대한민국 청소년 창업경진대회 사업계획서 양식에 맞게 연결되어야 한다.

신청서 양식 기준으로 다음 항목이 명확히 보이도록 구성해줘.

- 기본 정보
  - 지역
  - 학교급
  - 소속 학교명
  - 동아리명
  - 창업아이템명
  - 한 줄 아이템 설명
  - 해결하고 싶은 지역 문제

- 동아리 현황
  - 대표자/부대표자/지도교사 정보는 현재 MVP에 없으면 표시하지 않거나 “추후 입력 필요”로 처리
  - 팀 구성 표

- 창업 아이템 개요
  - 창업 아이템 소개
  - 차별성
  - 주요 고객 및 판매 전략
  - 이미지/설계도 아이디어

- 1. 문제인식
  - 1-1. 창업 아이템의 개발 동기
  - 1-2. 창업 아이템의 사회적 가치 창출

- 2. 실현가능성
  - 2-1. 창업 아이템의 발전 과정
  - 추진계획
  - 2-2. 시장 및 고객 분석
  - 2-3. 예상 장애 요소

- 3. 성장전략
  - 3-1. 필요 자원
  - 3-2. 판매 및 홍보 전략

- 4. 팀 구성
  - 구성원 담당 역할
  - 구성원의 역량
  - 갈등 해결 방법

- 창업동아리 활동 자료
  - 이미지 또는 설계도 아이디어
  - 추후 첨부자료 안내

## 15. HTML/PDF 저장 디자인 주의사항

기존 HTML 저장과 PDF 저장 기능은 유지해야 한다.

디자인 개편 시 다음을 반드시 확인해줘.

- 화면용 디자인과 출력용 디자인이 충돌하지 않게 구성
- `@media print` 또는 HTML export 스타일이 있다면 보존 또는 개선
- A4 출력 기준에서 섹션이 잘리지 않도록 고려
- 표가 페이지 중간에서 어색하게 깨지지 않도록 처리
- 배경색이 너무 진해 PDF 가독성을 해치지 않게 조정
- 최종 결과 HTML은 보고서로 저장했을 때도 전문적으로 보여야 함

## 16. 애니메이션 유지 조건

기존 단계별 애니메이션 효과는 그대로 유지해줘.

가능하면 다음 정도만 개선해줘.

- 단계 전환 시 부드러운 fade/slide
- 결과 카드 등장 시 stagger animation
- 버튼 hover / active 상태
- 선택 카드 scale 또는 border transition
- 과한 애니메이션 금지

주의:
애니메이션 때문에 입력값이 초기화되거나 단계 이동 로직이 깨지면 안 된다.

## 17. 접근성 및 사용성

- 텍스트 대비 충분히 확보
- 버튼 클릭 영역 충분히 확보
- 입력 필드 label 명확히 표시
- 오류 메시지는 색상만으로 전달하지 말고 텍스트도 제공
- 키보드 포커스 스타일 유지
- 청소년 사용자가 이해할 수 있는 쉬운 문구 사용
- 지도교사도 검토하기 쉬운 보고서형 구조
