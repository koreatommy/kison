# application-form-spec.md

## 1. 문서 목적

이 문서는 `AI 창업 아이템 선정하기 MVP`가 최종 산출물을 생성할 때 따라야 하는 **2026 대한민국 청소년 창업경진대회 사업계획서 신청서 양식 기준**을 정의한다.

본 문서는 Claude API 프롬프트, 최종 HTML 결과물, PDF 출력 화면, 향후 신청서 자동작성 기능의 기준 문서로 사용한다.

---

## 2. 참조문서

### 2.1 기준 양식

- 문서명: `2026 대한민국 청소년 창업경진대회 사업계획서 신청서 양식`
- 권장 파일 위치: `/docu/ai창업사업계획서/2026-youth-startup-application-form.pdf`
- 사용 목적: 최종 산출물 항목 구성, AI 작성 기준, HTML/PDF 출력 기준

### 2.2 적용 원칙

본 MVP는 신청서 PDF 원본을 직접 편집하지 않는다.

대신 신청서 양식의 핵심 항목을 구조화한 `ApplicationFormSpec`을 기준으로 AI 결과물을 생성한다.

---

## 3. 신청서 양식 핵심 구조

신청서 양식은 크게 아래 구조로 구성된다.

1. 기본 신청 정보
2. 동아리 현황
3. 창업 아이템 개요 요약
4. 문제인식
5. 실현가능성
6. 성장전략
7. 팀 구성
8. 창업동아리 활동 자료

이번 MVP의 범위는 **창업 아이템 선정하기**이므로, 모든 항목을 완성하지 않는다. 다만 최종 결과물이 이후 전체 사업계획서 작성으로 확장될 수 있도록 신청서 주요 항목과 연결되는 형태로 출력한다.

---

## 4. MVP에서 반드시 생성해야 하는 항목

### 4.1 기본 아이템 정보


| 신청서 항목                | MVP 생성 여부 | 설명                               |
| --------------------- | --------- | -------------------------------- |
| 창업아이템명                | 필수        | 최종 선택 아이템의 이름                    |
| 한 줄 아이템 설명            | 필수        | 누구의 어떤 문제를 어떤 방식으로 해결하는지 설명      |
| 주제                    | 필수        | 아이템의 핵심 주제                       |
| 우리 동아리가 해결하고 싶은 지역 문제 | 필수        | 문제 배경, 대상자, 기존 해결 방식의 한계, 해결 필요성 |


### 4.2 동아리 현황 일부


| 신청서 항목     | MVP 생성 여부 | 설명                          |
| ---------- | --------- | --------------------------- |
| 동아리명 또는 팀명 | 필수        | 시작 단계에서 입력                  |
| 구성원 학교     | 필수        | 시작 단계에서 입력                  |
| 구성원 학년     | 필수        | 시작 단계에서 입력                  |
| 구성원 이름     | 필수        | 시작 단계에서 입력                  |
| 담당역할       | 2차 개발     | 현재 MVP에서는 선택 항목 또는 자동 제안 가능 |
| 연락처, 이메일   | 제외        | 개인정보 최소화 원칙에 따라 입력받지 않음     |


### 4.3 창업 아이템 개요 요약


| 신청서 항목          | MVP 생성 여부 | 설명                                  |
| --------------- | --------- | ----------------------------------- |
| 창업 아이템 소개       | 필수        | 핵심 기능 중심으로 3개 이상 작성                 |
| 차별성             | 필수        | 기존 방식 또는 유사 아이템 대비 다른 점             |
| 주요 고객           | 필수        | 사용자, 구매자, 수혜자를 구분하여 작성              |
| 판매 전략           | 필수        | 학교, 지역기관, 공공기관, 학부모, 학생 등 대상별 확산 방식 |
| 홍보 전략           | 필수        | SNS, 캠페인, 학교 행사, 지역 연계 등 홍보 방식      |
| 이미지 또는 설계도 아이디어 | 필수        | 앱 화면, 서비스 흐름도, 제품 구조도, 포스터 등 제안     |

## 5. 사업계획서 본문 확장 항목

MVP의 최종 결과물은 아래 본문 항목까지 직접 완성하지 않더라도, 다음 단계 사업계획서 작성으로 확장 가능한 초안을 포함해야 한다.

### 5.1 문제인식

#### 5.1.1 창업 아이템의 개발 동기

작성 기준:

- 주변 또는 지역사회에서 발견한 문제에서 출발한다.
- 사용자가 입력한 불편 상황을 핵심 근거로 삼는다.
- 왜 이 문제를 해결하려고 하는지 구체적으로 작성한다.
- 청소년 창업동아리가 문제를 발견한 맥락이 드러나야 한다.

출력 형식:

- 2~3문장 문단
- 필요 시 bullet 2~3개

#### 5.1.2 창업 아이템의 사회적 가치 창출

작성 기준:

- 아이템을 통해 기대되는 긍정적 변화를 작성한다.
- 개인 편의뿐 아니라 학교, 지역사회, 취약계층, 환경, 안전 등 사회적 기여를 포함한다.
- 정량 데이터가 없으면 수치를 만들지 않는다.

출력 형식:

- 사회적 가치 3개 이상
- 각 항목은 한 문장으로 명확히 작성

### 5.2 실현가능성

#### 5.2.1 창업 아이템의 발전 과정

작성 기준:

- 아이디어 구체화 → 고객 인터뷰 → 시제품 제작 → 테스트 → 개선 순서로 작성한다.
- 청소년 동아리가 실제로 수행 가능한 수준으로 작성한다.
- 과도한 기술 구현 또는 고비용 개발 계획은 피한다.

#### 5.2.2 창업 아이템의 시장 및 고객 분석

작성 기준:

- 주요 고객을 구체적으로 정의한다.
- 고객의 문제 상황과 사용 맥락을 설명한다.
- 시장 규모나 통계는 확인되지 않으면 작성하지 않는다.
- 필요한 경우 `추후 조사 필요`로 표시한다.

#### 5.2.3 창업 아이템 개발 과정 중 예상되는 장애 요소

작성 기준:

- 기술적 장애 요소
- 사용자 참여 부족
- 예산 부족
- 개인정보 또는 안전 관련 우려
- 기존 서비스와의 차별성 부족

각 장애 요소에는 개선 방향을 함께 제시한다.

### 5.3 성장전략

#### 5.3.1 창업 아이템 개발을 위한 필요 자원

작성 기준:

- 인적 자원
- 기술 자원
- 협력 기관
- 예산
- 자료 조사
- 멘토링

청소년 동아리 수준에서 확보 가능한 방법을 함께 작성한다.

#### 5.3.2 판매 전략

작성 기준:

- 주 고객층
- 주요 타깃 시장
- 확산 경로
- 초기 도입 방법
- 수익화 가능성

단, MVP 단계에서는 과도한 매출 예측을 생성하지 않는다.

#### 5.3.3 홍보 전략

작성 기준:

- 학교 게시판
- SNS
- 카드뉴스
- 캠페인
- 지역기관 협력
- 체험 부스
- YEEP 활동 자료 연계

### 5.4 팀 구성

#### 5.4.1 구성원 담당 역할

작성 기준:

- 구성원별 강점과 역할을 연결한다.
- 현재 MVP에서는 사용자가 역할을 입력하지 않으면 AI가 임시 역할을 제안할 수 있다.
- 임시 역할은 `제안`으로 표시하고 확정 정보처럼 쓰지 않는다.

#### 5.4.2 구성원 역량

작성 기준:

- 조사 능력
- 발표 능력
- 디자인 역량
- 개발 역량
- 기획 역량
- 협업 역량

입력 정보가 부족하면 `추후 팀 역량 입력 필요`로 표시한다.

#### 5.4.3 구성원 간 갈등 해결 방법

작성 기준:

- 다수결만 제시하지 않는다.
- 의견 수렴, 근거 비교, 역할 분담, 회의 기록, 멘토 조언 등 절차를 포함한다.

## 7. FinalDocument 출력 스키마

Claude의 최종 문서 생성 결과는 아래 스키마를 따른다.

```ts
export interface FinalDocument {
  itemNameSuggestions: string[];
  selectedItemName: string;
  oneLineItemDescription: string;
  topic: string;
  localProblemToSolve: string;

  itemIntroduction: string[];
  differentiation: string[];
  targetCustomers: string[];
  salesStrategy: string[];
  promotionStrategy: string[];
  expectedSocialValue: string[];

  prototypeIdea: string;
  imageOrDiagramIdea: string;

  developmentMotivationDraft: string;
  feasibilityDraft: {
    developmentProcess: string[];
    marketAndCustomerAnalysis: string[];
    expectedObstacles: Array<{
      obstacle: string;
      solution: string;
    }>;
  };
  growthStrategyDraft: {
    requiredResources: string[];
    salesPlan: string[];
    promotionPlan: string[];
  };
  teamCompositionDraft: {
    suggestedRoles: Array<{
      memberName: string;
      suggestedRole: string;
      reason: string;
    }>;
    conflictResolutionMethod: string;
  };

  finalSelectionReason: string;
  limitationsAndNextResearch: string[];
}
```

## 9. Claude 프롬프트 삽입 규칙

최종 문서 생성 task에는 반드시 아래 정보를 포함한다.

```ts
const promptPayload = {
  workflowContext,
  applicationFormSpec: APPLICATION_FORM_SPEC,
  instruction: "신청서 양식 기준에 맞춰 최종 창업 아이템 선정 결과를 작성하세요.",
};
```

Claude에게 전달할 핵심 지시문:

```txt
당신은 청소년 창업경진대회 사업계획서 작성을 돕는 창업교육 전문 AI입니다.

아래 APPLICATION_FORM_SPEC은 최종 결과물이 따라야 할 신청서 양식 기준입니다.
출력은 반드시 이 기준에 맞춰 작성하세요.

중요:
1. 사용자가 선택한 문제 분야와 최종 선택 아이템을 변경하지 마세요.
2. 신청서 항목과 관계없는 장황한 설명을 생성하지 마세요.
3. 없는 통계, 시장 규모, 기관명, 법률 근거를 생성하지 마세요.
4. 확인되지 않은 내용은 '추후 조사 필요'로 표시하세요.
5. 청소년 창업동아리가 실행할 수 있는 수준으로 작성하세요.
6. 반드시 JSON 형식으로만 응답하세요.
```

## 11. 금지 표현 및 대체 표현

### 11.1 금지 표현

아래 표현은 근거가 없는 경우 사용하지 않는다.

- 국내 최초
- 세계 최초
- 시장 규모 ○○억 원
- 반드시 성공
- 완벽한 해결
- 100% 예방
- 모든 학생이 사용
- 정부 인증
- 특허 확보
- 투자 유치 완료
- 수익성 검증 완료

### 11.2 대체 표현


| 금지 표현       | 대체 표현                   |
| ----------- | ----------------------- |
| 국내 최초       | 기존 방식과 다른 접근을 시도함       |
| 반드시 성공      | 성공 가능성을 높일 수 있음         |
| 100% 예방     | 위험을 줄이는 데 기여할 수 있음      |
| 모든 학생       | 주요 대상 학생                |
| 시장 규모 ○○억 원 | 시장 규모는 추후 조사 필요         |
| 정부 인증       | 관련 제도 및 인증 여부는 추후 확인 필요 |

## 13. MVP 범위 제한

현재 MVP는 신청서 전체 자동 작성 서비스가 아니다.

현재 MVP의 목적은 다음이다.

1. 창업 아이템 후보를 발굴한다.
2. 후보를 평가한다.
3. 최종 창업 아이템을 선정한다.
4. 신청서 핵심 항목에 활용 가능한 문장을 생성한다.
5. HTML/PDF 결과물을 생성한다.

따라서 아래 항목은 2차 개발에서 다룬다.

- 대표자 연락처
- 부대표자 연락처
- 지도교사 정보
- YEEP 창업가정신 핵심역량 진단 수행 일자
- 전체 추진계획 일정표
- 구체적 예산안
- 고객 인터뷰 실제 결과
- 시장 규모 통계 자동 조사
- 활동 자료 이미지 업로드
- HWP/PDF 신청서 양식 직접 입력

## 15. 개발 완료 기준

`application-form-spec.md` 기준 개발 완료 조건은 아래와 같다.

1. `lib/applicationFormSpec.ts`에 `APPLICATION_FORM_SPEC` 상수가 구현되어 있다.
2. 최종 문서 생성 Claude task에 `APPLICATION_FORM_SPEC`가 포함된다.
3. 최종 HTML 결과물이 신청서 핵심 항목 순서에 맞게 출력된다.
4. 최종 PDF 출력 화면에서도 신청서 핵심 항목이 누락되지 않는다.
5. AI가 신청서 양식과 관계없는 장황한 설명을 생성하지 않도록 프롬프트가 구성되어 있다.
6. 없는 통계와 시장 규모를 생성하지 않도록 금지 규칙이 포함되어 있다.
7. 최종 선택 아이템명이 이후 단계에서 임의로 변경되지 않는다.
