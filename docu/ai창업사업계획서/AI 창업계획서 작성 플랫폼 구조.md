아래는 **「2026 대한민국 청소년 창업경진대회 사업계획서」 양식**을 기준으로, 청소년이 AI의 질문을 따라가며 창업계획서를 완성하는 플랫폼을 만들기 위한 단계별 기획안입니다. 신청서 양식은 **목차와 표를 변경·삭제할 수 없고**, 파란색 안내 문구는 삭제 후 검정색 글씨로 작성해야 하며, 필요 시 사진·이미지·표를 추가할 수 있는 구조입니다.

# 1. 플랫폼의 핵심 목표 정의

## 서비스 목적

청소년 창업팀이 막연한 아이디어를 입력하면, AI가 질문·피드백·검증·문장화를 통해 **대회 제출용 사업계획서 초안**을 자동 작성하도록 돕는 플랫폼입니다.

## 핵심 사용자

| 사용자     | 주요 목적                      |
| ------- | -------------------------- |
| 청소년 창업팀 | 아이디어 정리, 사업계획서 작성, 발표자료 준비 |
| 지도교사    | 학생 작성 내용 검토, 피드백, 제출 관리    |
| 멘토·운영자  | 항목별 코칭, 평가 기준 기반 피드백       |
| 기관 관리자  | 팀 관리, 신청서 현황 확인, 데이터 축적    |

# 4. AI 질문형 아이디어 구체화 단계

청소년은 처음부터 사업계획서를 잘 쓰기 어렵기 때문에, 문서 작성을 바로 시키면 품질이 낮아집니다. 따라서 **질문형 인터뷰 방식**으로 아이디어를 구체화해야 합니다.

## 추천 질문 흐름

| 단계       | 질문 목적       | 예시 질문                                   |
| -------- | ----------- | --------------------------------------- |
| 문제 발견    | 해결할 문제 찾기   | 주변에서 불편하거나 아쉽다고 느낀 문제는 무엇인가요?           |
| 대상 정의    | 고객 구체화      | 이 문제를 가장 많이 겪는 사람은 누구인가요?               |
| 기존 대안 확인 | 경쟁·대체재 파악   | 지금 사람들은 이 문제를 어떻게 해결하고 있나요?             |
| 아이템 정의   | 해결 방식 구체화   | 여러분의 아이디어는 이 문제를 어떻게 다르게 해결하나요?         |
| 차별성 도출   | 강점 정리       | 기존 방법보다 더 편리하거나 특별한 점은 무엇인가요?           |
| 실현가능성 검토 | 개발 가능성 확인   | 지금 가진 기술, 인력, 시간으로 어디까지 만들 수 있나요?       |
| 시장성 검토   | 고객·판매 전략 설계 | 이 아이템을 누구에게, 어떤 방식으로 알리고 판매할 수 있나요?     |
| 사회적 가치   | 공익성 연결      | 이 아이템이 학교, 지역사회, 청소년, 환경 등에 어떤 도움을 주나요? |

## 질문 방식

폐쇄형 질문과 개방형 질문을 섞는 방식이 적합합니다.

| 질문 유형    | 용도                    |
| -------- | --------------------- |
| 폐쇄형 질문   | 빠른 선택, 방향 설정, 난이도 조절  |
| 개방형 질문   | 창의적 아이디어 발굴, 문제 경험 수집 |
| AI 후속 질문 | 답변을 바탕으로 깊이 있는 구체화    |

예를 들어 처음에는 선택형으로 진입 장벽을 낮추고, 이후 AI가 개방형 질문으로 깊이를 확보하는 방식이 좋습니다.

# 9. AI 프롬프트 설계 방향

## 항목별 프롬프트 템플릿 필요

예를 들어 `1-1. 창업 아이템의 개발 동기`는 다음 구조로 AI가 작성해야 합니다.

```text
역할:
너는 청소년 창업경진대회 사업계획서 작성 코치다.

목표:
학생의 답변을 바탕으로 ‘창업 아이템의 개발 동기’를 작성한다.

작성 기준:
- 주변 또는 지역사회 문제를 중심으로 작성
- 문제의 구체적 상황을 설명
- 왜 이 아이템이 필요한지 연결
- 청소년다운 시각을 유지
- 과장된 시장 규모나 검증되지 않은 수치는 사용하지 않음
- 공식 사업계획서에 넣을 수 있는 문장으로 작성

입력:
[학생 답변]
[아이템명]
[해결하고 싶은 문제]
[대상 고객]

출력:
- 2개 문단
- 핵심 문장 3개
- 보완 질문 2개
```

이런 방식으로 각 항목마다 별도의 프롬프트를 설계해야 합니다.

# 12. MVP 우선순위

처음부터 모든 기능을 넣으면 개발 범위가 커집니다. MVP는 아래 5개에 집중하는 것이 좋습니다.

## MVP 핵심 5개

1. **공식 사업계획서 항목별 작성 화면**
2. **AI 질문형 인터뷰**
3. **항목별 사업계획서 초안 생성**
4. **AI 검토 및 보완 질문**
5. **PDF/DOCX 제출 문서 출력**

이 5개만 구현해도 플랫폼의 핵심 가치는 검증할 수 있습니다.

# 13. 차별화 포인트

이 플랫폼의 핵심 차별성은 단순한 문서 자동작성기가 아니라는 점입니다.

| 일반 AI 글쓰기 도구 | 본 플랫폼            |
| ------------ | ---------------- |
| 자유 입력 중심     | 공식 대회 양식 기반      |
| 긴 프롬프트 필요    | 질문형 인터뷰 방식       |
| 결과물 품질 편차 큼  | 항목별 작성 기준 적용     |
| 교사 검토 어려움    | 교사·멘토 피드백 구조 포함  |
| 제출 양식 변환 필요  | 제출 문서 자동 생성      |
| 청소년 수준 반영 부족 | 청소년 창업 교육용 UX 적용 |

# 14. 결론

이 플랫폼은 다음 순서로 기획하는 것이 가장 안정적입니다.

```text
공식 신청서 양식 분석
→ 항목별 질문 설계
→ AI 작성 프롬프트 설계
→ 학생용 작성 UX 설계
→ 교사용 검토 UX 설계
→ MVP 개발
→ AI 검토 기능 추가
→ 문서 출력 기능 고도화
→ 발표자료·멘토링·기관관리 기능 확장
```

우선 개발 방향은 **“청소년이 질문에 답하면 공식 사업계획서 양식에 맞춰 초안을 완성해주는 AI 작성 플랫폼”**으로 잡는 것이 가장 명확합니다.
다음 단계에서는 바로 **MVP 기능정의서(PRD)** 형태로 정리하는 것이 적절합니다.
