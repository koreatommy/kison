# 토큰 사용 정리 (startup-support 워크플로우)

## 1) 현재 프로젝트에서 토큰을 보는 방식

- 이 프로젝트는 DB 없이 동작합니다.
- 토큰 사용량은 서버 응답의 `usage` 값을 받아 클라이언트 상태에 누적합니다.
- 시작 페이지(` /dashboard/startup-support `)에서 `현재 토큰 사용현황` 버튼을 누르면 확인할 수 있습니다.

표시 항목.
- 총 호출 횟수.
- 누적 입력 토큰.
- 누적 출력 토큰.
- 누적 총 토큰.
- 최근 호출 task와 해당 호출의 토큰.

주의.
- 현재는 세션 메모리 기반입니다.
- 페이지 새로고침 시 누적값이 초기화됩니다.

---

## 2) 서버 로그에서 단계별 시간/토큰 확인

서버 로그는 task 기준으로 아래 형식으로 출력됩니다.

```text
[AI][generate_startup_items] success 68.2s input=12345 output=6789 total=19134
```

실패 시.

```text
[AI][evaluate_startup_items] failed 82.4s - ...
```

이 로그로 단계별 소요시간과 토큰 소비를 동시에 확인할 수 있습니다.

---

## 3) 단계별 예상 소요시간(화면 안내)

워크플로우에서 AI 버튼이 있는 단계에 안내 문구가 추가되어 있습니다.

- 아이템 생성: 약 1분 ~ 1분 20초.
- 아이템 평가: 약 1분 20초 ~ 1분 40초.
- 신청서 문장 생성: 약 1분 30초 ~ 2분.

공통 주의 문구.
- 생성/평가 중에는 브라우저를 닫거나 새로고침하지 말아야 합니다.

또한 각 단계 완료 후 `최근 실제 소요시간`이 화면에 표시됩니다.

---

## 4) 이번 측정값(사용자 제공 통계 기준)

사용자 제공 수치.
- 총 입력 토큰: `36,967`
- 총 출력 토큰: `26,696`
- 총합: `63,663`

해석.
- 1회 실행 기준으로는 큰 편입니다.
- 특히 출력 토큰 비중이 커서 비용 영향이 큽니다.

---

## 5) 비용 계산 (Claude Sonnet 4.6 기준)

단가.
- 입력: `$3 / 1M tokens`
- 출력: `$15 / 1M tokens`

1회 비용 계산.
- 입력 비용: `36,967 / 1,000,000 × 3 = $0.1109`
- 출력 비용: `26,696 / 1,000,000 × 15 = $0.4004`
- 합계: `약 $0.5113` (약 51센트)

$20 크레딧 기준 사용 가능 횟수.
- `20 / 0.5113 ≈ 39회`
- 안전 범위로는 약 `35~40회`로 보는 것이 적절합니다.

한화 환산(예시 환율 1달러=1,380원).
- `$0.51 × 1,380 ≈ 704원`
- 대략 `700원~720원` 범위.

---

## 6) 비용 절감 권장사항

효과 큰 순서.
- `generate_final_document` 출력 길이 제한 (문장 수/글자 수).
- 평가 단계 배열 길이 제한 (강점/약점/보완 항목 수 제한).
- 프롬프트 컨텍스트 축약 (중복/불필요 원문 제거).
- `max_tokens` 상한 재튜닝.

추가 옵션.
- 응답 지연 허용 가능 시 Batch API 검토.
- 반복되는 고정 프롬프트는 Prompt Caching 검토.

---

## 7) 운영 관점 메모

- DB 없이도 실시간/세션 단위 토큰 모니터링은 가능합니다.
- 장기 추세 분석(일/주/월), 팀 단위 집계, 디바이스 간 공유가 필요하면 DB나 외부 로그 저장소가 필요합니다.
- 현재 구조는 "빠른 로컬 검증 + Vercel 배포"에 적합한 형태입니다.
